# pi-raindrop

Raindrop.io bookmarks and collections in pi.

## Install

```bash
pi install https://github.com/goofansu/pi-raindrop
```

## Requirements

- `RAINDROP_API_KEY`: a Raindrop.io API key or test token.
- [secretspec](https://secretspec.dev) CLI, for `make dev` only.

## Feature

- `raindrop` tool: get, create, and update bookmarks, and list collections.
- `raindrop` skill: workflow guidance for bulk updates and background metadata parsing.
